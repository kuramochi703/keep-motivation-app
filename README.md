# サボると、やつれる。

机に向かった日を記録すると、**サボった日数だけアバターがやつれていく**習慣化アプリ。

このファイルは**入口**です。アプリの機能と仕組み、環境構築、どこを触ればいいかをまとめています。

## 1. 何ができるアプリか

```text
目標を決める  →  毎日5分タイマーを回す  →  続けるとアバターが育つ
                                        →  サボるとやつれる
```

画面は3つです。

| 画面 | 何をするか | ファイル |
| --- | --- | --- |
| **トップ** | たまごが出迎える。ここから始める | `src/pages/TopPage.tsx` |
| **目標設定** | 目標・期限・頻度・アバターの種類と名前を決める | `src/pages/SetupPage.tsx` |
| **ダッシュボード** | アバター・活力ゲージ・5分タイマー・カレンダー | `src/pages/MainPage.tsx` |

ダッシュボードでできること:

- **5分タイマー**：▶ を押すと開始。5分たつと今日の達成として記録される
- **「記録だけつける」**：タイマーを回さずに今日を達成にする。その日すでに達成済みなら出ない
- **カレンダー**：週表示と月表示。達成率と連続日数もここで集計している
- **期限の延長 / 目標の作り直し / 最初から**

## 2. ゲームのルール

### 活力（0〜100）— 今の調子

`src/state/logic.ts` の定数がすべてです。

| 定数 | 値 | 意味 |
| --- | --- | --- |
| `GAIN` | 12 | 達成した日に増える活力 |
| `DECAY` | 20 | サボった日に減る活力 |
| `SESSION` | 300 | タイマーの秒数（5分） |

活力は5段階（`levelOf()`）に丸められ、アバターの**表情・姿勢・色の鮮やかさ**になります。

### 成長ステージ（1〜6）— どこまで育ったか

**のべ達成日数で決まり、下がりません。** 活力とは独立した軸です
（定義は `src/avatar/stage.ts`）。

| 日数 | 名前 | 増えるもの |
| --- | --- | --- |
| 0日 | ひよこ | からだ・あし・くちばし |
| 3日 | やんちゃひよこ | つばさ |
| 7日 | もふもふ | 一回り大きくなる |
| 14日 | いっちょまえ | とさか |
| 30日 | りりしい | マフラー |
| 60日 | まんまるの主 | 冠 |

**2軸が独立しているので、「ステージ6なのにボロボロ」も「ステージ1で絶好調」も成立します。**
育った達人がやつれているほうが、ひよっこがやつれるより効きます。

さらに**アバターの種類**（もりお／だいち／こむぎ）が色相（緑・青・ピンク）を決めます。

> なぜ2軸にしたか: 活力1本だと **4日で上限に張り付いて**、そこから先は何をしても
> 見た目が変わりませんでした。「今日の体調の表示」であって育成ではなかったためです。

## 3. 「やつれる」が動く仕組み

アバターがやつれる瞬間を1つ追うと、全体の流れが見えます。

1. 1日サボる（達成しない）
2. 次にアプリを開く → `logic.ts` の `rollover()` が「前回からサボった日がないか」を数える
3. サボった日ぶん **活力を20ずつ引く**
4. `avatar/look.ts` が活力を受けて「彩度が抜けて、うつむいた」見た目に変える

**「活力という数字」⇔「絵の変化」がルールブック1つでつながっている**のがこのアプリの心臓部です。

```text
ボタンを押す → logic.ts で計算 → useApp.ts が状態を更新
            → 画面が描き直される → 同じ内容を Supabase に保存
```

## 5. 動かす

### 初回だけ

**Node.js v20 以上**（推奨 v22 / v24）が必要です。

```bash
node -v && npm -v          # command not found なら nodejs.org の LTS を入れる

git clone https://github.com/kuramochi703/keep-motivation-app.git
cd keep-motivation-app
npm install                # 数分かかることがある
```

**環境変数**を用意します。`.env.example` をコピーして `.env` を作り、値を入れてください。

```bash
cp .env.example .env
```

| 変数 | 中身 |
| --- | --- |
| `VITE_SUPABASE_URL` | Supabase プロジェクトの URL |
| `VITE_SUPABASE_ANON_KEY` | Supabase の anon key |

> **鍵は Git に入れません。** `.env` は `.gitignore` 済み。共有はチャットの DM などで。

### 毎回

```bash
npm run dev                # → http://localhost:5173/
```

保存した瞬間にブラウザへ反映されます（HMR）。止めるのは `Ctrl + C`。

| コマンド | 何をするか | いつ使うか |
| --- | --- | --- |
| `npm install` | ライブラリを入れる | 初回 / `package.json` が変わった時 |
| `npm run dev` | 開発サーバー起動 | 開発中ずっと |
| `npm run build` | 型チェック＋本番用に書き出し | **push する前に必ず** |
| `npm run preview` | `build` の結果を確認 | 本番の見た目を確かめたい時 |

## 6. ソースの歩き方

```text
src/
├── main.tsx          Reactの起動（基本さわらない）
├── app/              画面の骨組み（App.tsx / Sidebar.tsx）
├── pages/            画面（トップ / 目標設定 / ダッシュボード）
├── features/         機能ひとまとまり（いまは calendar/ だけ）
├── state/            状態とルール
│   ├── logic.ts        ルールブック。活力計算・達成判定・日付計算
│   ├── useApp.ts       リモコン。下の3つを1つのAPIにまとめる
│   ├── useScreen.ts    画面遷移だけ
│   ├── useTimer.ts     5分タイマーだけ
│   └── useGoalState.ts 目標の状態と Supabase への保存
├── avatar/           アバター（3Dのひよこ）。README.md に触り方あり
├── lib/supabase.ts   DBの接続クライアント
└── ui/               配色・ロゴ・全体スタイル
```

**1ファイル＝1つの仕事**が原則です。迷ったら:

| やりたいこと | 触る場所 |
| --- | --- |
| 活力の増減など**ルール**を変える | `src/state/logic.ts` |
| 画面の構成・ボタンの動き | `src/pages/` `src/app/` |
| 色・レイアウト | `src/ui/styles.css` |
| アバターの色・表情・ステージの中身 | `src/avatar/look.ts` |
| アバターの**形** | `src/avatar/models/chick.blend`（[触り方](./src/avatar/README.md)） |
| 進化に必要な日数 | `src/avatar/stage.ts` |

構成の詳しい図は [ARCHITECTURE.md](./ARCHITECTURE.md) にあります。

## 7. 困ったとき

| 症状 | 対処 |
| --- | --- |
| `npm: command not found` | Node.js が未インストール |
| `Cannot find module 'react'` | `npm install` のし忘れ |
| ポート 5173 が使用中 | 別のターミナルで起動中。`Ctrl+C` か `npm run dev -- --port 5174` |
| 画面が真っ白 | `F12` → Console タブの赤いエラーを読む |
| データが読めない / 保存されない | `.env` の2つの値が正しいか。Console に `Supabase読み込みエラー` が出ていないか |
| アバターが出ない（枠だけ） | WebGL が使えない環境。Console に `[avatar]` で始まる警告が出る |
| どうにもならない | `rm -rf node_modules package-lock.json && npm install` |

**WSL / Windows の人へ**: WSL 内で `npm run dev` しても、通常は Windows 側のブラウザから
`http://localhost:5173/` で開けます。開けない場合は `npm run dev -- --host` で起動し、
表示された Network アドレスを使ってください。
