# アバターの描き方（react-three-fiber）

アバターは **three.js（react-three-fiber）で組んだ 3D のひよこ**です。
モデルファイル（.glb など）は使わず、**球や円錐を並べてコードだけで形を作っています。**

外部ファイルに依存しないので、絵を描ける人を待たずに誰でも `npm run dev` で
見た目をいじれます。数値を変えて画面を見る、の繰り返しで調整してください。

---

## ファイルの役割

| ファイル | 中身 | こんな時に触る |
| --- | --- | --- |
| `Avatar.tsx` | 入口。3D を出すか SVG に落とすかを決める | ほぼ触らない |
| `look.ts` | 「ステージ × 活力」→ 見た目パラメータの対応表 | **色・表情・何段階目で何が生えるかを変えたい** |
| `Chick.tsx` | パラメータを受けて実際に形を組む | **形そのものを変えたい** |
| `AvatarCanvas.tsx` | カメラと照明 | 明るさ・アングルを変えたい |
| `stage.ts` | のべ達成日数 → 成長ステージ | 進化に必要な日数を変えたい |
| `AvatarSvg.tsx` | 3D が使えない時に出る従来の SVG | ほぼ触らない |
| `avatar.css` | 表示サイズ | 大きさを変えたい |

## 見た目を決める軸

```text
種類  もりお / だいち / こむぎ  ← 目標設定でユーザーが選ぶ。色相が変わる
軸1  成長ステージ 0〜6         ← のべ達成日数で決まる。下がらない。 体格・装備が変わる
軸2  活力 0〜100              ← やれば＋、サボれば−。上下する。   彩度・表情・姿勢が変わる
```

### 種類（`logic.ts` の `AVATARS` / `look.ts` の `VARIANTS`）

| id | 名前 | 色 |
| --- | --- | --- |
| 0 | もりお | みどり |
| 1 | だいち | あお |
| 2 | こむぎ | ピンク |

**名前と説明は `logic.ts` の `AVATARS`、色は `look.ts` の `VARIANTS` にあります。**
種類を増やすときは両方に足してください。並び順が id と対応しています。

### 軸1：ステージで増えるもの（`stage.ts` と `look.ts`）

| ステージ | 日数 | 名前 | 増えるもの |
| --- | --- | --- | --- |
| 0 | 0 | たまご | 殻のまま。ゆらゆら揺れる |
| 1 | 1 | ひよこ | からだ・あし・くちばし |
| 2 | 3 | やんちゃひよこ | つばさ |
| 3 | 7 | もふもふ | しっぽ（からだも大きくなる） |
| 4 | 14 | いっちょまえ | とさか |
| 5 | 30 | りりしい | マフラー |
| 6 | 60 | まんまるの主 | 冠 |

### 軸2：活力で変わるもの（`look.ts`）

| 活力 | レベル | 目 | 姿勢・色（色相は種類、彩度は活力で決まる） |
| --- | --- | --- | --- |
| 90〜 | 4 絶好調 | ∩（笑い） | 色が最も鮮やか。ほっぺが赤い。まわりに光の粒 |
| 70〜 | 3 元気 | まるい目 | 鮮やか。ほっぺが少し赤い |
| 45〜 | 2 ふつう | まるい目 | ふつう |
| 20〜 | 1 しょんぼり | ∪（下向き） | 彩度が落ちる。少しうつむく。汗をかく |
| 〜19 | 0 ボロボロ | 閉じている | 灰色に近い。深くうつむく。ほとんど動かない |

**「ステージ6でボロボロ」も「ステージ1で絶好調」も成立します。**
2軸は独立しているので、片方を変えてももう片方は壊れません。

## いじる時のコツ

### 数値はすべて `r`（からだの半径）の倍率で書く

```tsx
// ◯ ステージが上がって r が変わっても比率が保たれる
<mesh position={[0, r * 1.2, 0]} />
// ✕ ステージ1では合っていても、ステージ6でずれる
<mesh position={[0, 0.9, 0]} />
```

### パーツが「消える」時は、たいてい球に埋まっている

three.js は物体どうしが重なっても外側だけが見えます。半径 `hr` の頭に
顔のパーツを貼るなら、中心を表面の位置まで押し出さないと中に飲み込まれます。
`Chick.tsx` の `faceZ()` がその計算をしているので、顔まわりは必ずこれを使ってください。

### 色は必ずカンマ区切りの `hsl()` で書く

`hsl(50 80% 70%)`（CSS の新しい書き方）は three.js が解釈できず、**黙って白になります。**
`hsl(50, 80%, 70%)` と書いてください。`look.ts` の `hsl()` ヘルパーを通せば安全です。

## 3D が使えない環境では

WebGL が無い環境と、3D の初期化に失敗した場合は、従来のインライン SVG
（`AvatarSvg.tsx`）を表示します。アプリは止まりません。
切り替わった時はコンソールに `[avatar]` で始まる警告が出ます。

three.js は容量が大きい（gzip で 250KB ほど）ので、3D は本体とは別に
遅延読み込みしています。読み込みが終わるまでの一瞬も SVG が出ます。

---

## モデルファイル（.glb）に差し替えたくなったら

Blender などで作った 3D モデルを使う方式にも移せます。その場合は
`Chick.tsx` を `useGLTF` を使うものに差し替え、`look.ts` の値を
モデルのモーフやマテリアルに割り当ててください。
**`look.ts` の対応表はそのまま使えます。** そのために形の組み立てと
仕様を別ファイルに分けてあります。
